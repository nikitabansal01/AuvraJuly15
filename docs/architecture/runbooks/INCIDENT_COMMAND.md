# Incident command runbook

1. Name an incident commander, scribe and technical lead; record UTC start,
   scope and user impact without health content or credentials.
2. Stabilize with reversible, read-only checks first. Preserve evidence and
   declare escalation paths for security/privacy/clinical concerns.
3. Give timed updates, record decisions/owners, verify recovery and open
   follow-ups for missing tests, alerts, runbooks or acceptance evidence.
